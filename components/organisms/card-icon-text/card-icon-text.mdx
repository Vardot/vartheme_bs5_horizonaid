# Icon Text Card

A badge-style Bootstrap card with an optional uploaded icon image and a single drag-and-drop content slot. Controls icon size and alignment, border, padding, background, shadow, border radius, equal height, and full-card stretched link. Headings dropped in the content slot switch to the accent color on hover.

- **Icon is optional** — upload an image to `icon_image` to show it above the content; leave empty for a plain content card
- `icon_alignment` positions the icon: `start` (left), `center`, `end` (right)
- **One content slot** — drop a Heading and a Text component together to form the title and description
- Headings dropped in the content slot are styled with `--bs-secondary` at rest and switch to `--bs-accent` on hover — leave their text color empty so this can apply
- `stretched_link` requires `link_url` to be set — makes the entire card clickable
- `padded: true` adds `p-4` to the card body; `padded: false` removes all padding
- `equal_height: true` adds `h-100` for consistent heights in grid row layouts
- `bg-primary-subtle` and `bg-accent-subtle` reproduce the brand's gold and blue badge card variants

## Examples

### Example 1 — Default (primary subtle, left icon)

```twig
{% embed 'vartheme_bs5_horizonaid:card-icon-text' with {
  icon_image: { src: '/path/to/icon.svg', alt: '', width: 64, height: 64 },
  icon_alignment: 'start',
  background_color: 'bg-primary-subtle',
  box_shadow: 'shadow-none',
  corner_style: 'rounded-4',
} %}
  {% block content %}
    <h3 class="h5">Title card</h3>
    <p class="mb-0">Description text</p>
  {% endblock %}
{% endembed %}
```
