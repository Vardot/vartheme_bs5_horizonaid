# Accordion block

A single accordion item with a clickable header, a plus/minus icon toggle, and a collapsible body slot. Use this component inside an **Accordion container** for grouped behavior, or standalone with `always_open: true` for an independent toggle.

- `open_by_default: true` expands the item when the page first loads
- The header title switches to the accent color on hover; the plus icon fades its vertical stroke into a minus on expand
- `heading_level` controls the semantic heading tag wrapping the button — choose the correct level for your document outline
- `item_id` produces stable, predictable IDs for deep-linking and automated testing
- `always_open: true` lets this item stay open independently even when nested in a grouped accordion
- Expand/collapse is a plain class toggle handled by `accordion-block.js` — no Bootstrap Collapse plugin is used, so the body height animates via CSS `grid-template-rows` instead of a measured pixel height

> ### Bootstrap documentation
> - [Accordion component](https://getbootstrap.com/docs/5.3/components/accordion/)

## Examples

### Example #1: Basic item, closed by default

```twig
{% embed 'vartheme_bs5_horizonaid:accordion-block' with {
  title: 'What is included?',
  heading_level: 3,
  open_by_default: false,
} %}
  {% block accordion_content %}
    <p class="mb-0">This section contains the accordion body content.</p>
  {% endblock %}
{% endembed %}
```

### Example #2: Item with a stable ID

```twig
{% embed 'vartheme_bs5_horizonaid:accordion-block' with {
  title: 'Billing details',
  heading_level: 3,
  item_id: 'billing-details',
  open_by_default: true,
} %}
  {% block accordion_content %}
    <ul class="mb-0">
      <li>Monthly invoicing</li>
      <li>Tax summary</li>
      <li>Payment methods</li>
    </ul>
  {% endblock %}
{% endembed %}
```

### Example #3: Rich body content

```twig
{% embed 'vartheme_bs5_horizonaid:accordion-block' with {
  title: 'Shipping & returns',
  heading_level: 3,
  open_by_default: true,
} %}
  {% block accordion_content %}
    <p>Free standard shipping on orders over $50.</p>
    <ul class="mb-0">
      <li>Standard: 5–7 business days</li>
      <li>Express: 2–3 business days</li>
    </ul>
  {% endblock %}
{% endembed %}
```
