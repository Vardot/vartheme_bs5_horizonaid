# Accordion container

A wrapper that manages a group of collapsible **Accordion block** items, stacked in a flex column with a fixed gap. The container owns the shared ID and controls whether multiple items can be open simultaneously.

- `always_open: true` lets multiple items be expanded at the same time
- Nested items can still override the container's grouping individually with their own `always_open: true`
- Leave `id` empty to have the container generate a unique ID automatically
- Items always keep their own rounded corners and background — there is no edge-to-edge "flush" mode

> ### Bootstrap documentation
> - [Accordion component](https://getbootstrap.com/docs/5.3/components/accordion/)
> - [Always open accordion](https://getbootstrap.com/docs/5.3/components/accordion/#always-open)

## Examples

### Example #1: Grouped FAQ accordion

```twig
{% embed 'vartheme_bs5_horizonaid:accordion-container' with {
  id: 'faq-accordion',
  always_open: false,
} %}
  {% block accordion_content %}
    {% embed 'vartheme_bs5_horizonaid:accordion-block' with {
      title: 'How do I reset my password?',
      heading_level: 3,
      open_by_default: true,
      item_id: 'faq-password',
    } %}
      {% block accordion_content %}
        <p class="mb-0">Go to the login page and click Forgot password.</p>
      {% endblock %}
    {% endembed %}

    {% embed 'vartheme_bs5_horizonaid:accordion-block' with {
      title: 'Can I change my email address?',
      heading_level: 3,
      open_by_default: false,
      item_id: 'faq-email',
    } %}
      {% block accordion_content %}
        <p class="mb-0">Yes. Navigate to Account settings and update your email.</p>
      {% endblock %}
    {% endembed %}
  {% endblock %}
{% endembed %}
```

### Example #2: Always-open (multiple expanded)

```twig
{% embed 'vartheme_bs5_horizonaid:accordion-container' with {
  id: 'support-topics',
  always_open: true,
} %}
  {% block accordion_content %}
    {% embed 'vartheme_bs5_horizonaid:accordion-block' with {
      title: 'Topic 1',
      open_by_default: true,
    } %}
      {% block accordion_content %}
        <p class="mb-0">This item can stay open with other items.</p>
      {% endblock %}
    {% endembed %}

    {% embed 'vartheme_bs5_horizonaid:accordion-block' with {
      title: 'Topic 2',
      open_by_default: true,
    } %}
      {% block accordion_content %}
        <p class="mb-0">Both items are open simultaneously.</p>
      {% endblock %}
    {% endembed %}
  {% endblock %}
{% endembed %}
```

### Example #3: One independent item in a grouped container

```twig
{% embed 'vartheme_bs5_horizonaid:accordion-container' with {
  id: 'mixed-group',
} %}
  {% block accordion_content %}
    {% embed 'vartheme_bs5_horizonaid:accordion-block' with {
      title: 'Grouped item',
      heading_level: 3,
      open_by_default: true,
    } %}
      {% block accordion_content %}
        <p class="mb-0">Opening this closes its grouped siblings.</p>
      {% endblock %}
    {% endembed %}

    {% embed 'vartheme_bs5_horizonaid:accordion-block' with {
      title: 'Independent item',
      heading_level: 3,
      open_by_default: true,
      always_open: true,
    } %}
      {% block accordion_content %}
        <p class="mb-0">This one stays open regardless of the others.</p>
      {% endblock %}
    {% endembed %}
  {% endblock %}
{% endembed %}
```
