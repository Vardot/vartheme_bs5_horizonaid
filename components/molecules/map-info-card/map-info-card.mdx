# Map Info Card

A small dismissible card — heading, description, up to two stat rows, and a "Learn More" link. Used standalone, or dropped into `organisms/map`'s `countries` slot (with `country_code` set) to become that country's click popup.

- **This card is always fully self-rendered** — set `country_code` and drop it into `organisms/map`'s `countries` slot; the map discovers it by its `data-country-code` attribute and shows/hides it on click. Nothing else to wire up.
- Stat rows (`stat_1_*` / `stat_2_*`) are independently optional — each row only renders when its `_value` is set
- The close button is progressive enhancement — the card renders fine without JS, it just won't dismiss
